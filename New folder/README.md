# Campus Lost & Found — Web Application

A visual directory and lost-and-found recovery portal designed for university campuses.

## Features
- **Search & Claim Module**: Live search and keyword filter with authenticated ownership claim verification.
- **Report Item (Lost / Found)**: Comprehensive reporting form with photo attachment, campus location tagging, and smart match detection.
- **Photo Upload Verification**: Direct camera capture or file upload for item verification.
- **All Campus Records Table**: In-memory database mirroring with CSV export and real-time status tracking.
- **User Management**: Multi-role authentication (Student, Staff, Administrator) with password visibility toggle.
- **Physical Collection Center**: Located in front of 3x3 Basketball Court, under C3 Hostel.

## Deployment
- **Static Hosting**: Ready to deploy on Netlify Drop, GitHub Pages, or Vercel.
- **Python Backend**: Can be executed locally or on cloud servers using `python server.py`.
